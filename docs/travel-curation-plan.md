# 旅行资料拟清洗片段对照表

本文件是 Task 1.2 的已确认设计记录，不是清洗资料，也不复制原始资料正文。后续 Task 1.3 仅能在用户明确授权后，依照此表创建 `knowledge/` 分层与清洗片段。

## 共同边界

- 每条片段只对应一个地点、一个路线方案、一个餐饮或住宿对象，或一条可独立使用的建议。
- 两条方向不同的钟山路线是替代方案，必须保留为不同的 `route_variant`，不得合并。
- 门票、联票、观光车、交通、营业状态、套餐、预约、天气、海况、船次和价格均为历史参考或需要实时验证的信息。
- 图片只保留与来源片段的关联；没有单独授权文字说明时，图片不进入文字检索。
- 《南京的旅游攻略》标记为 `first_hand_experience`；其余旅行攻略标记为 `personal_collection`（来自网红推荐）。原始外部链接未提供，保持 `unknown`，不补造。
