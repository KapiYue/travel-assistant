# 智能旅行助手 · 移动端交互原型

直接在浏览器打开 [index.html](index.html) 即可体验，无需安装依赖或启动服务。桌面并列显示“需求拆分、助手查询、逐日行程”三个画面；手机上通过右上角的 1／2／3 切换画面，也可以沿着页面内的链接前进。

可体验的路径：

1. 在底部输入旅行需求并按回车或点击紫色按钮，或使用初始的三亚示例；点击“补充旅行条件”可修改出发城市、目的地、天数、预算、同行人和偏好。
2. 在第一个画面展开或收起任务拆分；点击“查看路线与助手建议”进入第二个画面。
3. 在第二个画面切换助手，点击路线卡选择路线，并查看会员权益栏目；选择路线后会更新第三个画面 Day 1 的下午安排。
4. 在第三个画面向下滚动查看各天行程，编辑当天主题或活动，新增、删除、收藏活动。点击“预订”会说明该航班信息仅是示例。

这是独立的静态原型，按提供的三屏 UI 参考实现。推荐、住宿、交通、航班价格与会员权益均为演示草案，未接入 AI 模型、地图、实时价格、库存或预订接口。编辑仅保存在当前页面内，刷新后会重置。它不代表项目阶段 1 的后端任务已完成。
